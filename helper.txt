Angular things
inject function - to get dependencies
signal function - Informs to Angular about a component changes.
                  `readonly recipe = signal<Recipe | null>(null);`
                  recipe can be only Recipe or null.

import: [] - Components, directives, pipes, modules, etc. which are being used within current component

selector - it will be the name of the component
           selector: armen ->  <armen></armen>

Hook - a method, which calls somehow, without our usage.

@Input - A decorator, which allows angular, to provide the field from the parent component to child(inner) component.
```
// Ребёнок
@Component({
  selector: 'app-recipe-card',
  template: `<h3>{{ recipe.getName() }}</h3>`,
})
export class RecipeCard {
  @Input() recipe!: Recipe;  // ← принимает от родителя
}

// Родитель
@Component({
  selector: 'app-recipe-list',
  imports: [RecipeCard],
  template: `
    @for (r of recipes(); track r.getId()) {
      <app-recipe-card [recipe]="r" />  <!-- ← передаёт ребёнку -->
    }
  `,
})
export class RecipeList {
  readonly recipes = signal<Recipe[]>([]);
}
```

Angular components have life cycle from creation to destruction.
And there are several points within creation and destruction.
And every cycle has its Interface.
Angular Interfaces and methods:
There are 9 of them
1) constructor
2) OnChanges, ngOnChanges
3) OnInit, ngOnInit
4) DoCheck, ngDoCheck
5) AfterContentInit, ngAfterContentInit
6) AfterContentChecked, ngAfterContentChecked -
7) AfterViewInit, ngAfterViewInit -
8) AfterViewChecked, ngAfterViewChecked -
9) OnDestroy, ngOnDestroy

Every component stage -> CREATE, UPDATE, DELETE
1) CREATE
   . constructor - When DI services is being provided to component constructor
   . ngOnChanges - When parent passes a value into a child(current component)
   . ngOnInit - When we need to provide data dor the component.
   . ngAfterViewInit - When view(current html template) is drawn
   . ngAfterContentInit - no need (when parent gives a html component into the child)

2) UPDATE
   . ngDoCheck - no need
   . ngOnChanges - When parent changes value
   . ngAfterViewChecked - no need
   . ngAfterContentChecked - no need

3) DESTROY(DELETE)
   . ngOnDestroy - For instance, here we are supposed to unsubscribe all of the evenListeners.

Angular syntax
1) {{ }} - To put any text in the text field of element.
 `<h1>{{ recipe.getName() }}</h1>`
 We can't do thing like these:
 - {{ x = 5 }}
 - new, function, return
 Only expressions

2) [] - To put data in ELEMENT (not class) property
        For example img element has src property
        ```
        <img [src]="recipe.getImageUrl()" />
        ```
3) () - To bind an eventListener
        `<button (click)="loadRecipe()">Load</button>`
        $event - A special variable which contains DOM event object
                 `<input (input)="onInput($event)" />` -> `onInput(event: Event): void {
                                                            const target = event.target as HTMLInputElement;
                                                            console.log(target.value);
                                                          }`

Things like recipe.getName(), recipe.getImageUrl(), loadRecipe() are component class fields or methods, (recipe, loadRecipe)

4) Control flow — @if, @for, @switch
   ```
   @if (isLoading()) {
     <p>Loading...</p>
   } @else if (error()) {
     <p>{{ error() }}</p>
   } @else {
     <p>Ready</p>
   }
   ```
   The code above is equal to the code below
   ```
   if (component.isLoading()) {
     // создать <p>Loading...</p>
   } else if (component.error()) {
     // создать <p>{{ error() }}</p>
   } else {
     // создать <p>Ready</p>
   }
   ```
   isLoading, error are just custom components methods or fields.

   ```
   @for (r of recipes(); track r.getId()) {
     <app-recipe-card [recipe]="r" />
   }
   ```
   Без track Angular при изменении массива пересоздаёт все элементы. С track — обновляет только те, что изменились.

   ```
   @switch (status()) {
     @case ('loading') { <p>Loading...</p> }
     @case ('success') { <p>Success</p> }
     @default { <p>Unknown</p> }
   }
   ```

   A component html file is not able to read private fields.methods.
